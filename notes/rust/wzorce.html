Wzorce

Dopasowywanie kształtów danych — od match po destructuring w domknięciach.

Gdzie wolno wzorce

  • Dopasowania bez warunków (irrefutable): let, for, parametry funkcji i domknięć — wzorzec musi pasować zawsze.
  • Dopasowania warunkowe: match, if let, while let, let ... else — mogą nie pasować; w if let wiązania działają tylko w gałęzi trafionej.

Anatomia wzorca

match przedmiot {
    Punkt { x: 0, y } => println!("na osi pionowej, y = {y}"),
    Punkt { x, y: 0 } => println!("na osi poziomej"),
    Punkt { x, y } if x == y => println!("na przekątnej"),
    Punkt { .. } => {}          // reszta pól bez wiązania
    Kolo { promien: p @ 1.0..=5.0, .. } => {}  // @ wiąże, zakres pasuje
}
  • Literał dopasowuje wartość; nazwa wiąże; _ ignoruje wszystko.
  • .. pomija resztę pól/elementów; @ łapie wartość do zmiennej przy okazji sprawdzania zakresu/wzorca.
  • | alternatywa: 1 | 2 | 3 =>.

Destructuring

let (a, _, c) = trojka;                       // krotka
let Osoba { imie, wiek: w, .. } = os;         // struktura, skróty i zmiana nazwy
let [pierwszy, .., ostatni] = &tablica;       // tablica/slice: .. w środku

for (indeks, wartosc) in lista.iter().enumerate() { }

Wzorce zagnieżdżają się dowolnie: Some((x, Ok(_))) rozkłada opcję, krotkę i wynik naraz. Taka dekompozycja to najczytelniejszy sposób rozpakowywania wyniku po wyniku.

if let i while let

if let Some(w) = opcja { uzyj(w); }

while let Some(w) = iterator.next() { przetwarz(w); }

let Some(n) = parsuj(s) else { return; }   // let-else: wiązanie + wcześniejsze wyjście

Jeśli potrzebujesz zachować wszystkie warianty, wybierz match; if let to skrót, gdy interesuje Cię jedna gałąź (plus ewentualny else).

Podsumowanie

Wzorce w Rust to osobny, spójny język dopasowywania kształtów: kompaktowy, sprawdzany pod względem wyczerpania i wszechobecny. Znajomość .., @, zakresów i zagnieżdżeń wystarcza na 95% przypadków.

Ćwiczenia

1. Jaka jest różnica między _ a nazwaną zmienną z #[allow(unused)] we wzorcu?

Oba wiążą/ignorują, ale _ nie wiąże w ogóle (nie trzyma wartości i nie porusza własnością przy rozstaniowym wzorcu), a nazwa wiąże — stąd ostrzeżenie, gdy jej nie używasz. Przy danych „tylko do zajrzenia" _ bywa dokładniejsze: nie przedłuża życia wartości.

2. Kiedy if let jest lepsze od match, a kiedy gorsze?

Lepsze, gdy gałęzi jest jedna istotna — mniej szumu. Gorsze, gdy inne warianty też coś robią: match wymusza wymienienie ich wszystkich, więc nowe warianty enuma nie prześlizgną się niezauważone.

3. Co robi Punkt { x: x @ 1..=3, .. }?

Pasuje do punktów, których współrzędna x mieści się w zakresie 1..=3, i wiąże tę wartość ze zmienną x. .. ignoruje pozostałe pola struktury bez konieczności ich wymieniania.
