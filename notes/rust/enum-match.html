Enum i dopasowanie

Warianty z danymi i match jako główny narzędzie rozumowania.

Enum z pakunkiem

Każdy wariant może nieść inne dane — enum to bezpieczna suma typów:

enum Ruch {
    Start,
    Skok { wysokosc: u8 },
    Atak(u16, u16),
}

enum Opcja<T> { Pelnia(T), Brak }   // tak naprawdę Option<T>

Option<T> zastępuje null: brak wartości jest typem w systemie, więc kompilator każe obsłużyć obie możliwości. To najczęstszy powód, dla którego Rust nie ma wyjątków NullPointerException.

match

fn opisz(r: &Ruch) -> &str {
    match r {
        Ruch::Start              => "start",
        Ruch::Skok { wysokosc }   => "skok",        // wiązanie pola
        Ruch::Atak(x, y)          => if x == y { "po przekątnej" } else { "atak" },
    }
}
  • Wyczerpywalność: brakujące warianty = błąd kompilacji. _ => łapie resztę.
  • Wzorce wiążą fragmenty wartości do nowych zmiennych (Atak(x, y)).

if let i let...else

Gdy interesuje nas tylko jeden wariant, pełny match to nadmiar:

if let Some(n) = liczba {
    println!("jest: {n}");
}

let Some(s) = odczyt() else {
    println!("brak danych");
    return;                 // gałąź else musi kończyć ścieżkę
};

let...else to idiom na "sprawdź warunek, przy niepowodzeniu wyjdź", bez zagnieżdżania if.

Podsumowanie

Enum niesie dane i wymusza rozważenie każdego przypadku. Option zastępuje null, match musi być wyczerpujący, a if let / let else skracają codzienne użycie.

Ćwiczenia

1. Dlaczego Option<T> jest lepszy od wartości "null"?

Brak wartości jest widoczny w typie. Funkcja zwracająca Option nie da się użyć jak gotowej wartości — trzeba ją "rozpakować", więc zapomnienie o sprawdzeniu to błąd kompilacji, nie awaria w produkcji.

2. Co trzeba zrobić, gdy w match nie obsługiesz jednego wariantu enuma?

Kompilator nie przepuści kodu — dopisz brakujące ramię albo _ =>. To samo dotyczy dodania nowego wariantu do enuma później: kod sam się posypie i znajdzie wszystkie newralgiczne miejsca.

3. Zamień na if let: match opcja { Some(x) => println!("{x}"), None => {} }.

if let Some(x) = opcja { println!("{x}"); } — pusty brakujący przypadek w match to dokładnie to, co robi samotne if let.
