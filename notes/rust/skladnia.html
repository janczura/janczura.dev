Podstawy składni

Zmienne, typy, funkcje i sterowanie przepływem.

Zmienne, stałe, cieniowanie

  • let x = 5; — niemutowalne; let mut y = 5; — mutowalna.
  • const MAX: u32 = 100_000; — stała: zawsze typowana, znana w czasie kompilacji, ważna w całym zasięgu.
  • Cieniowanie (shadowing) — ponowne let z tą samą nazwą tworzy nową zmienną, może być innego typu:
let spaces = "   ";          &str
let spaces = spaces.len();    // u32 — nowa zmienna, nie zmiana wartości

Typy

Skalarne: i32/u64/f64/bool/char (4 bajty, obejmuje Unicode). Złożone: krotka (i32, f64) i tablica [i32; 3] — oba o stałej długości. Destruktoracja:

let (a, b) = (1, 2.5);     // krotka
let ([first, .., last]) = [1, 2, 3];

Funkcje

Parametry zawsze wymagają adnotacji typu. Ostatnie wyrażenie bloku (bez średnika) jest wartością zwracaną; jawne wyjście to return. Kluczowa różnica: instrukcje (let, println!) nie zwracają wartości, wyrażenia (if, match, blok) — zwracają. Dlatego let x = if ... działa, a let y = (let z = 3); nie. 

fn pole(szer: u32, wys: u32) -> u32 {
    szer * wys          // bez średnika = zwróć
}

let liczba = 3;
let opis = if liczba % 2 == 0 { "parzysta" } else { "nieparzysta" };

Sterowanie

  • if/else if/else — warunek musi być bool (bez "falsy" wartości).
  • loop — nieskończona pętla, może zwracać wartość przez break wartość;; etykiety pozwalają przerywać zagnieżdżone pętle.
  • while — powtarza dopóki warunek prawdziwy.
  • for — nad iteratorem, najczęściej nad zakresem:
for i in 1..5 { println!("{i}"); }      // 1,2,3,4
for i in 1..=5.rev() { }                // wstecz: 5,4,3,2,1

Podsumowanie

Typy jawne lub wywodzone przez kompilator, ale adnotacja przy funkcjach obowiązkowa. Wszystko jest wyrażeniem — if i bloki zwracają wartości. Cieniowanie to nowa zmienna, nie mutacja. Warunki wyłącznie typu bool.

Ćwiczenia

1. Czym różni się let mut x = 5; od ponownego let x = 6;?

mut modyfikuje tę samą zmienną w miejscu — typ musi pozostać ten sam. Ponowne let (cieniowanie) tworzy zupełnie nową zmienną; może mieć inny typ i nie wymaga mut.

2. Jak odwrócić kolejność tablicy [1, 2, 3] i zwrócić sumę?

Przejść pętlą for wstecz ((0..arr.len()).rev()) i sklejać wartości, albo użyć iteratora: arr.iter().rev().sum(). Suma wynosi 6.

3. Dlaczego let x = if true { 3 }; jest błędne?

if użyty jako wyrażenie musi zwracać wartość z każdej gałęzi — brak else oznacza gałąź zwracającą () (unit), czyli typy gałęzi się nie zgadzają (i32 vs ()).
