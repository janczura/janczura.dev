Kolekcje

Wektor, tekst i mapa — trzy fundamenty codziennej pracy.

Wektor

let mut v = Vec::new();
v.push(1); v.push(2);
let v2 = vec!["a", "b"];              // makro z literałem

match v.get(10) {                        // get zwraca Option — bez paniki
    Some(x) => { },
    None => { },
}
v[0] += 1;                              // indeksowanie panikuje poza zakresem

for x in &mut v { *x *= 2; }             // iteracja z pożyczką mutalną

Wszystkie elementy muszą mieć ten sam typ; na mieszankę — enum w środku wektora.

Tekst

String to bufor na stosie (właściciel), &str — wycinek (pożyczka). Tekst jest UTF-8, więc indeksowanie liczbowe bywa niedozwolone — s[1] to bajt, nie znak; wielobajtowe znaki leżą na kilku indeksach. 

let mut s = String::from("tektur");
s.push_str("a");
let polaczenie = format!("{s} i {s}");   // nowa alokacja

for c in s.chars() { }                  // znaki (Unicode)
for b in s.bytes() { }                  // bajty

HashMap

use std::collections::HashMap;

let mut licznik: HashMap<String, u32> = HashMap::new();
licznik.insert(String::from("ala"), 1);

if let Some(n) = licznik.get("ala") {      // Option<&u32>
    println!("liczba: {n}");
}

let n = licznik.entry(String::from("ma")).or_insert(0);
*n += 1;                                 // entry: wstaw tylko gdy brak klucza

get zwraca Option — brak klucza to normalna sytuacja, nie awaria. entry(...).or_insert(...) to najkrótsza droga do liczników słów. Mapa ma losową kolejność iteracji.

Podsumowanie

Vec z get/push, tekst jako para String/&str świadomy UTF-8, HashMap z get i entry. Brak wartości = Option, brak cichych awarii przy indeksie z get.

Ćwiczenia

1. Dlaczego s[1] na tekście z emoji może być błędem?

Indeksowanie działa bajtami. Emoji zajmuje np. 4 bajty — "środek" znaku nie jest granicą i indeksowanie w środku sekwencji UTF-8 panikuje. Bezpieczniej: get(1..), chars() albo wycinki po znalezionych granicach.

2. Policz wystąpienia słów w zdaniu.

zdanie.split_whitespace().fold(HashMap::new(), |mut m, slowo| { *m.entry(slowo).or_insert(0) += 1; m }) — wzorzec entry().or_insert() działa też na pożyczonych kluczach &str.

3. Kiedy użyć vec!["x"; 3], a kiedy pętli z push?

vec![x; n] tworzy n kopiów tej samej wartości (element musi być Clone). Gdy elementy mają się różnić albo powstają kosztownie — pusty Vec::new() i push w pętli.
