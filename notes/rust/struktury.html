Struktury i metody

Grupowanie powiązanych danych i zachowanie przy nich.

Tworzenie i inicjalizacja

struct Prostokat { szers: u32, wys: u32 }

let szers = 30;
let p = Prostokat { szers, wys: 10 };        // skrót gdy nazwa pola = nazwa zmiennej
let q = Prostokat { wys: 5, ..p };            // resztę bierze z p

Warianty: krotkowa struct Punkt(i32, i32) (dostęp przez p.0) i jednostkowa struct Marker; — zero danych, przydatna jako typ-marka.

Wyprowadzanie zachowań

Zwykłe struktury nic nie potrafią wypisać czy porównać — trzeba to derywować: #[derive(Debug, Clone, PartialEq)] plus drukowanie przez {p:?} (lub {:#?} — wieloliniowo).

Metody

Metody definiuje się w bloku impl. Pierwszy parametr decyduje o pożyczce: &self (czyta), &mut self (zmienia), self (zjada obiekt). Przy wywołaniu self jest niejawne: p.pole(), nie Prostokat::pole(&p). 

impl Prostokat {
    fn nowy(szers: u32) -> Prostokat {        // funkcja stowarzyszona (konstruktor)
        Prostokat { szers, wys: szers }
    }

    fn pole(&self) -> u32 { self.szers * self.wys }

    fn powieksz(&mut self, o: u32) { self.wys += o; }
}

let mut p = Prostokat::nowy(10);
p.powieksz(5);
println!("pole = {}", p.pole());

Funkcje bez self nazywa się stowarzyszonymi i wywołuje przez Typ::funkcja() — standard na konstruktory. Bloków impl może być wiele dla jednego typu.

Podsumowanie

struct + skrót pól + update syntax ..; zachowanie w impl. Wybór pożyczki w sygnaturze (&self / &mut self / self) to de facto API typu. #[derive(Debug)] i {:?} do podglądu.

Ćwiczenia

1. Kiedy użyć self zamiast &mut self w metodzie?

Gdy metoda chce przejąć i "zużyć" obiekt — zwrócić przekształconą wartość albo przerobić strukturę o inny typ (builder). Po takim wywołaniu oryginalna zmienna jest już nieaktywna, bo własność przeszła do metody.

2. Co się stanie przy let q = Prostokat { wys: 5, ..p }; jeśli p nie implementuje Copy?

Jeśli struktura ma typy nie-kopiowalne (np. pole String), nieprzejęte pola zostaną przeniesione z p do q, a p przestanie działać. Przy samych u32 kopiowanie jest ciche i p wciąż żyje.

3. Dodaj do struktury Punkt metodę zwracającą odległość od początku układu.

fn dist(&self) -> f64 { ((self.x * self.x + self.y * self.y) as f64).sqrt() } — &self, bo tylko czytamy pola; rzutowanie na f64 przed sqrt.
